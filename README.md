# Hospital Capacity Prediction Using Machine Learning

## Project Overview
This project uses machine learning classification techniques to categorize hospitals into Low, Medium, and High bed-capacity classes based on hospital directory data.

## Dataset
- Source: National Hospital Directory with Geo Code and Additional Parameters (data.gov.in)
- Records: 30,273
- Attributes: 48
- Target variable: Bed_Category (Low, Medium, High)

## Machine Learning Models
1. K-Nearest Neighbors (KNN)
2. Naive Bayes
3. Decision Tree
4. Support Vector Machine (SVM)
5. Random Forest

## Technologies Used
Python, Pandas, NumPy, Matplotlib, Scikit-learn

## Model Results

| Model | Accuracy |
|---|---:|
| Naive Bayes | 77.38% |
| Random Forest | 72.62% |
| Decision Tree | 72.62% |
| SVM | 71.43% |
| KNN | 66.67% |

## Conclusion
Naive Bayes achieved the highest accuracy among the five classification models in this experiment.
